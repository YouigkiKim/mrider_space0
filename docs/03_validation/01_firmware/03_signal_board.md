# 신호 기판 검증 — Teensy 4.1 소켓 기판

납땜한 신호 기판이 배치도대로인지 확인하는 방법과 결과.
배치와 납땜은 [신호 기판 납땜 가이드](../../02_guide/01_firmware/03_signal_board_guide.md),
연결표는 [신호 기판 설계](../../01_development/01_firmware/03_signal_board_design.md) §3을 본다.

- 좌표는 (열, 행). 1–3단계는 **Teensy를 뺀 채로**, 전원 없이 한다.

---

## 1. 눈으로

- 이웃 구멍끼리 납이 이어진 곳(브리지)이 없다.
- 버스가 끊긴 곳이 없다(3.3 V 위·아래, GND, GND 세로선).
- R3·R4가 **뒷면**에, R5 자리에 **점퍼선**, R6 자리는 **비어** 있다.
- 헤더 가운데 구멍 3곳에 아무것도 납땜되지 않았다.

## 2. 단락 (멀티미터 저항 또는 도통)

| 측정 | 기대 |
|---|---|
| 3.3 V(위) 버스 – GND | 열림(OL) |
| 3.3 V(아래) 버스 – GND | 열림 |
| PWR +5 V – GND | 열림 |
| 3.3 V(위) – 3.3 V(아래) | **열림 (정상)** — Teensy 안에서만 이어진다 |
| PWR GND – GND 버스 | **열림 (정상)** — PWR GND는 Teensy GND 패드(4, 11)로 가고, Teensy 안에서 GND 버스와 이어진다 |
| 이웃한 신호끼리 (SDA–SCL, A–B, 핀 20–21) | 열림 |

## 3. 도통 (단자 → 소켓 패드)

| 단자·헤더 | 반대쪽 | 기대 |
|---|---|---|
| PWR +5 V | Vin 패드 (3, 11) | 삐 |
| PWR GND | GND 패드 (4, 11) | 삐 |
| RELAY GATE / SENSE | 핀 21 (8, 11) / 핀 20 (9, 11) | 삐 |
| STRS SDA / SCL | 핀 18 (11, 11) / 핀 19 (10, 11) | 삐 |
| STRP 3.3 V | 3.3 V(위) 버스, 3V3 패드 (5, 11) | 삐 |
| STRP GND | GND 패드 (17, 11) | 삐 |
| DRVS A / B | 핀 0 (4, 17) / 핀 1 (5, 17) | 삐 |
| DRVP 3.3 V | 3.3 V(아래) 버스, 3V3 패드 (17, 17) | 삐 |
| i-BUS 신호 (23, 2) | 핀 15 (14, 11) | 삐 (R5 점퍼선 경유) |
| PWM 1 신호 / PWM 2 신호 | 핀 2 (6, 17) / 핀 3 (7, 17) | 삐 |
| IMUS 위 SCL1 (26, 26) / 아래 SDA1 (26, 28) | 핀 16 (13, 11) / 핀 17 (12, 11) | 삐 (1호 기판 납땜대로 — 위·아래가 원본과 반대) |
| IMUP 3.3 V | 3.3 V(아래) 버스 | 삐 |
| IMUP GND | GND 버스 | 삐 |
| SDA1 – SCL1 (나란히 가는 두 선) | 서로 | **열림** |
| DRVP·i-BUS·PWM 1·PWM 2의 GND | GND 버스 (아래 GND 패드 (3, 17) 포함) | 삐 |
| 헤더 가운데 3곳 | 어디와도 | **연결 없음** |
| 핀 18·19 패드 | 3.3 V(위) 버스 | 약 4.7 kΩ (R1·R2) |
| 핀 0·1 패드 | 3.3 V(아래) 버스 | 약 10 kΩ (R3·R4) |

## 4. 전압 (Teensy를 꽂고)

- **전원 넣기 전 도통:** Teensy를 꽂으면 PWR GND – GND 버스, 3.3 V(위) – 3.3 V(아래)가 **삐** 소리가 나야 한다(Teensy 안에서 이어짐).
- Teensy `VUSB`–`VIN` 절단 여부를 먼저 적는다. 잘랐다면 PWR에 5 V(전류 제한)를 넣고, 안 잘랐다면 **PWR에 전원을 넣지 말고** USB만 쓴다.

| 측정점 | 기대 |
|---|---|
| Vin – GND | 약 5 V |
| 3.3 V(위)·(아래) 버스 – GND | 3.3 V |
| SDA·SCL (핀 18·19) | 3.3 V (통신 없을 때) |

## 5. 기판 위에서 스케치 다시 돌리기

벤치(Stage 0)와 같은 결과가 나오면 통과. 방법은 [Stage 0 검증](../01_firmware/test_bench.md), [조향 벤치 검증](../01_firmware/02_steering_bench.md) §2.

| 스케치 | 통과 기준 |
|---|---|
| `i2c_scan` | `PASS 0x36 alone.` |
| `as5600_check` | `GAP OK`, AGC 40–90 |
| `quad_count` | 순서대로 대면 ±4 |
| `ibus_monitor` | 약 130 fr/s, `bad 0` |
