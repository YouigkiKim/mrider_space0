## 1. i-BUS 대기 전압 — R5·R6 결정

Teensy 4.1은 5 V를 견디지 못하므로 i-BUS 선을 핀 15에 연결하기 **전에** 잰다
(`docs/build/03-electrical.md` §3.5.4 R5·R6 표, §3.5.1 RC 표).

**준비**

- 수신기 FS-iA6B에 **5 V만** 공급한다. B/VCC 줄의 **가운데 핀 = +**. Teensy는 연결하지 않는다.
- 송신기 FS-i6을 켜고 수신기 LED가 **깜빡이지 않고 계속 켜져 있는지** 확인한다(바인딩됨).

**i-BUS 포트 위치** (라벨을 바로 읽는 방향, B/VCC가 위)

- 채널 블록(CH1–CH6, B/VCC) 왼쪽에 따로 있는 **세로 1열**이다.
  - 위 3핀 = **i-BUS SERVO** → Teensy에 연결하는 포트
  - 아래 3핀 = i-BUS SENS → 텔레메트리 센서용, 쓰지 않음

**방법**

1. 도통(전원 끔): i-BUS 가운데 핀과 채널 블록 가운데(+) 열 사이에서 삐 소리가 나면 가운데 = +.
2. DC 전압(전원 켬, 검은 리드 GND): SERVO 3핀을 각각 잰다.

**판정**

| 신호 핀 값 | R5 | R6 |
|---|---|---|
| 약 3.3 V | 점퍼선 | 생략 |
| 약 5 V | 분압기 직렬 저항 | 분압기 GND 쪽 저항 |

- 가운데 핀은 **+5 V 전원**이다. 신호로 착각하지 않는다.
- 멀티미터는 평균값을 보여 주므로, 프레임이 오가는 동안에는 대기 전압보다 약간 낮게 읽힌다.

## 2. i-BUS 수신 — `ibus_monitor`

**연결:** SERVO 위 핀(신호) → Teensy 핀 15, SERVO 아래 핀(GND) → Teensy GND. 가운데(+)는 연결하지 않는다.
수신기 전원은 별도 5 V. 켜는 순서는 Teensy(USB) → 수신기.

**방법:** `firmware/bench`에서 `pio run -e ibus_monitor -t upload` → `pio device monitor`

| 확인 | 통과 기준 |
|---|---|
| 송신기 끔 | 줄이 계속 나오고 `NO FRAMES YET` (USB·스케치 정상) |
| 송신기 켬, LED 계속 켜짐 | **약 130 fr/s**, `bad 0`이 늘지 않음, `age … OK` |
| 채널 배치 | 스틱·스위치를 하나씩 움직여 어느 CH가 변하는지 기록. CH5(MUX SEL)는 2단 스위치여야 한다 |
| 송신기 다시 끔 | `NO FRAMES for … ms` 또는 값이 계속 옴(failsafe) — 어느 쪽인지 기록 (조향 설계 D2) |
