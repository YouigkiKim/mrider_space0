# 테스트 벤치 검증 — Stage 0 센서

센서 배선이 맞는지 확인하는 방법. 회로는 [Stage 0 회로도](../../02_guide/01_firmware/images/stage0_bench_schematic.svg),
자세한 설명은 [Teensy 가이드](../../02_guide/01_firmware/01_teensy_guide.md) 7.3절을 본다.

- 명령은 `firmware/bench` 폴더에서 실행한다.
- 업로드: `pio run -e <스케치> -t upload` (첫 시도가 실패하면 한 번 더)
- 출력 보기: `pio device monitor` (업로드 후 Teensy가 다시 연결될 때까지 10~15초 기다린 뒤)

---

## 1. 멀티미터로 전압 확인

USB를 꽂은 상태에서, 검은 리드는 GND에 대고 잰다.

| 측정점 | 기대값 |
|---|---|
| Teensy 3.3V 핀, 브레드보드 `+` 레일 | 3.3 V |
| AS5600 VCC, DRV5013 1번 다리(VCC) | 3.3 V |
| SDA(핀 18), SCL(핀 19) | 3.3 V (통신이 없을 때) |
| DRV5013 3번 다리(OUT) = 핀 0·1 줄 | 0 V 또는 3.3 V |

- 단락 확인: USB를 뺀 상태에서 핀 18·19와 GND 사이 저항이 수 kΩ 이상이어야 한다(0 Ω이면 단락).

## 2. 홀센서 — 자석 대 보기 (멀티미터)

- OUT과 GND 사이를 재면서 자석을 DRV5013 **인쇄면(좁은 쪽)** 에 댄다.
- S극 → 0 V, N극 → 3.3 V, **자석을 치워도 값이 유지**되면 정상(래치).

## 3. 홀센서 — 모니터로 카운트 확인 (`quad_count`)

- S극을 A → S극을 B → N극을 A → N극을 B 순서로 대면 `count`가 한 방향으로 **±4**.
- 같은 동작을 B부터 하면 반대 방향으로 ±4.
- 바퀴에 장착한 뒤: 한 바퀴에 **±36**, 앞으로 굴릴 때 `count`가 증가하는지 기록.

## 4. 조향각 센서 — I²C 통신 확인 (`i2c_scan`)

- 출력이 `PASS  0x36 alone.`이면 정상.
- `nothing answered` → SDA·SCL 배선·풀업·센서 전원 확인. `N devices` → 버스에 장치가 여러 개.

## 5. 조향각 센서 — 수치 확인 (`as5600_check`)

- 직경 방향 자석(반 N, 반 S)을 칩 한가운데 위에 평행하게 둔다.
- 상태 문구가 `GAP OK`, **AGC 40~90(목표 64)** 가 되는 거리를 찾아 기록한다.
- 자석을 제자리에서 돌리면 `raw`가 0~4095 사이에서 부드럽게 변해야 한다.
- 책상에서 한 바퀴 넘게 돌릴 때 뜨는 `WRAPPED`는 무시한다(진짜 wrap 검사는 차량 장착 후 좌우 끝까지).
