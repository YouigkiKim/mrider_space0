# 릴레이 구동 기판 검증

릴레이 구동 기판을 만드는 동안과 만든 뒤에 확인하는 방법, 통과 기준, 결과.
만드는 순서와 구멍 위치는 [릴레이 구동 기판 가이드](../../02_guide/03_relay_board/01_relay_board_guide.md) §4를 본다.

- 좌표는 (열, 행). 1–4는 **전원 없이**, 5–7은 전원을 넣고 한다.
- 이 기판은 벤치 버전이 없다. **각 단계를 통과해야 다음 부품을 단다.**

## 5. 첫 전원: 코일 구동

벤치 전원 **12 V, 전류 제한 1 A** → PWR. 릴레이 코일을 K1–K4에 연결.

| 조건 | 기대 |
|---|---|
| GATE 연결 안 함 | 딸깍 없음, 전류 수 mA 이하 → **STOCK** |
| GATE에 3.3 V (같은 GND) | **딸깍 4번**, 전류 약 600 mA → **DBW** |
| 3.3 V 뗌 | 다시 딸깍, 전류 원래대로 → STOCK |
| 3.3 V 상태에서 DRAIN ↔ GND 전압 | 약 0 V (Q1 켜짐) |
| GATE 연결 안 함 상태에서 DRAIN ↔ GND 전압 | 약 12 V (코일을 거쳐) |

## 6. E-stop 감지 (R3·R4를 단 뒤)

| 조건 | 기대 |
|---|---|
| 12 V 넣음, TEENSY SENSE ↔ GND | 약 2.55 V (12.0 V 기준, `12 × 2.7 / 12.7`) |
| 12 V 뺌 (E-stop을 누른 것과 같음) | 0 V |
| 어떤 경우에도 | **3.3 V 미만**. 넘으면 Teensy에 잇지 않는다 |

## 7. 신호 기판과 연결 후 (`estop_relay_check`)

케이블: TEENSY GATE ↔ 신호 기판 RELAY GATE(핀 21), TEENSY SENSE ↔ RELAY SENSE(핀 20). GND 선은 잇지 않는다.

| 확인 | 기대 |
|---|---|
| 전원을 켠 직후 | STOCK (게이트 LOW, 딸깍 없음) |
| E-stop 풀림 | 감지 HIGH |
| `g` 입력 | 딸깍 4번 → DBW |
| E-stop 누름 | 감지 LOW, 코일 꺼짐 → STOCK (하드웨어로) |
| 감지 선을 뽑음 | 감지 LOW (스케치가 내부 풀다운을 씀 — 끊긴 선은 "멈춤"으로 읽혀야 한다) |
| 한 번 누름·뗌 | 튐은 **20 ms 안에 끝나고**, 누른 채·뗀 채로는 전환 0 `[POLICY]` |

- 튐 기준은 원본에 없는 팀 기준이다. 20 ms는 스케치가 튐으로 세는 간격(`kBounceMs`)이다.
  처음에는 "전환 1번(튐 0)"이었는데, 기계식 접점은 누를 때와 뗄 때 늘 조금 튀므로 지킬 수 없는 기준이었다(2026-11-28 결과).
  튐은 펌웨어 규칙으로 무해하다: LOW는 첫 순간에 멈추고, HIGH는 hold-off 뒤에도 RC 재허가가 있어야 다시 출발한다
  (`docs/build/04-firmware.md` §4의 E-stop 규칙). 펌웨어는 **hold-off 중 LOW가 한 번이라도 오면 hold-off를 처음부터 다시 센다.**

### 7단계 상세 (2026-11-28, `4ac7652`, 바퀴 들고)

| 확인 | 결과 |
|---|---|
| 전원 직후 STOCK | **미확인** (12 V를 넣을 때 딸깍이 없었는지 기록하지 않음) |
| E-stop 풀림 | `sense HIGH` |
| `g` | `gate HIGH -> DBW`. 딸깍 1번으로 들림(4개가 동시에 붙음). K1–K4 각각 손끝 진동 확인 |
| E-stop 누름 | 첫 LOW와 같은 ms에 `gate LOW -> STOCK`, 릴레이 떨어짐 |
| 누른 채 `g` | `refused: sense is LOW` |
| `x` | `gate LOW -> STOCK` |
| 감지 선을 뽑음 | 6.5초 동안 계속 `sense LOW`, 다시 꽂으면 `HIGH` |
| 튐 | 누를 때 전환 9번, 뗄 때 11번. **모두 1 ms 안**에 끝나고 그 뒤로는 안정 → 새 기준으로 통과 |
| 선 흔들기 | 다시 꽂은 직후 전환 4번 외에는 0 |
| `g`/`x` 10번 | 릴레이가 붙고 떨어질 때 감지는 한 번도 바뀌지 않음 (코일 전류가 감지를 흔들지 않음) |

- 커넥터를 뽑고 꽂는 1초 남짓 동안 감지가 수천 번 바뀌었다(뽑을 때 약 2,550번, 꽂을 때 약 170번). 핀이 미끄러지는 동안이라 정상이다.
  시험 전 아무것도 하지 않았는데 112번 바뀐 기록이 있는데, 크기가 꽂을 때와 비슷해 그 무렵 커넥터를 건드린 것으로 본다.
- 시험은 스케치의 시리얼 포트를 PC 스크립트로 열고 키(`g`/`x`)를 보내며 기록했다. E-stop 조작과 소리·진동 확인은 사람이 했다.
